# GitHub Copilot - Product Requirements Document (PRD) Example
Use GitHub Copilot - in VSCode or the CLI - to analyize meeting transcripts and other documents to generate a requirements document, which can then be used to create an initial backlog of work.

## Scenario
The Contoso company is having an internal meeting to discuss and kick-off a new project. Key business stakeholders have expressed the need to analyze social media platforms, to be able to more quickly detect trends and tune their product offerings and promotions in response.

## Using AI to Accelerate the Project
An initial meeting transcript has been provided from an initial project overview.
